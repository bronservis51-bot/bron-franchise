# Закупки из МойСклад

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox syntax.

**Цель.** Франчайзи видит проведённые закупки и возвраты. Менеджер видит закупки УК у поставщиков и себестоимость отгрузок.

**Архитектура.** Отдельный серверный загрузчик читает четыре вида документов и их позиции, сверяет полноту и сохраняет снимки. RPC применяют проверенные привязки на дату документа и ограничивают поля по роли. Расходы и оплаты ведутся по действующему учёту.

**Стек.** TypeScript, React Query, PostgreSQL, Node.js, Vitest, systemd.

**Спецификация.** [Согласовано 26 ноября](../specs/2026-11-26-franchise-procurement-and-royalty-design.md).

## Общие ограничения

- Только чтение API серверным токеном. Сохранять источник, валюту, дату снимка и предыдущий успешный снимок.
- Принадлежность по подтверждённому UUID и дате документа. Нераспределённые по точке закупки остаются на уровне партнёра. Себестоимость УК только у менеджера.
- Автоматические записи в МойСклад и в расходы не входят в пилот. Первая сверка охватывает текущий и предыдущий месяц.
