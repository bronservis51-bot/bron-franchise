# Демо-проект Supabase приостановлен

**Признаки:** экран входа отвечает «Сервер недоступен»; в панели Supabase проект в статусе Paused (Free-проекты останавливаются после 7 дней без активности).

**Ограничение ущерба:** данные при паузе сохраняются; новые операции невозможны — сообщить участникам демо.

**Восстановление:** Supabase Dashboard → проект → Restore/Resume project (несколько минут). Проверить вход менеджера и франчайзи.

**Профилактика:** перед демонстрацией открыть стенд за день; на время пилота — еженедельная активность или решение о постоянном хостинге. Платный тариф автоматически не подключать.

**Коммуникация:** сообщение участникам: «Стенд был приостановлен провайдером из-за неактивности, данные сохранены, работа восстановлена в HH:MM».
