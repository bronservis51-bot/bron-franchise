# Тестовый кабинет на телефоне

Стенд использует отдельный HTTPS-адрес и учебные профили. Он собирается из выбранной версии кабинета. Данные создаёт локальный сервер проекта через собственные миграции и учебные примеры. Для почтовой отправки, МойСклад и Google Sheets нужна отдельная тестовая настройка.

## Как пользоваться

Откройте [стенд](https://preview.152-228-115-115.sslip.io/) в браузере телефона и войдите в один из учебных профилей. Пароль учебных профилей выдаётся владельцу по закрытому каналу.

| Роль | Логин |
| --- | --- |
| Менеджер по франшизе | `set` |
| Франчайзи | `fran` |
| Управляющий | `uprav` |
| Продавец | `sales` |
| Стажёр | `staz` |

Для проверки под другой ролью выйдите из профиля кабинета и войдите снова. Через меню браузера стенд можно добавить на главный экран как «Бронь — тест».

## Как загрузить другую сборку

1. Откройте чистый checkout выбранного коммита с каталогом `deploy/preview`. Выполните `bash deploy/preview/build.sh <полный SHA> <абсолютный путь к пакету>`. Запишите SHA-256 пакета.
2. Передайте пакет на VPS по закреплённому SSH. Запустите `deploy/preview/install.sh <абсолютный путь к пакету> <SHA-256 пакета>` под согласованным административным доступом. Команда проверяет пакет, стартует сервисы стенда и обновляет только адрес стенда.
3. Сверьте `/preview-version.json`. Проверьте, что свежая вкладка сразу показывает форму входа и что запросы к данным требуют действующего токена. Повторите необходимые действия на тестовом профиле. Для рабочего выпуска используется отдельная команда выпуска Timeweb.

Новая сборка обычно стартует с исходных учебных данных. При смене пароля с той же схемой используйте `BRON_PREVIEW_PRESERVE_DATA=1` с `install.sh`. Установщик копирует остановленную учебную базу, меняет пароль только пяти учебных профилей и сохраняет прежний набор для отката. Пароль хранится в закрытом `/etc/bron-mobile-preview/api.env`. Сервис учебной базы доступен через loopback. Прокси ограничивает попытки входа, сервис базы проверяет токены.

Тестовый адрес использует отдельный origin на DNS-сервисе sslip.io, пока у `preview.bronservis.ru` нет записи. Для перехода на собственный адрес сначала создаётся DNS-запись. Затем согласованно меняются виртуальный хост Caddy, разрешённый адрес прокси и адрес API в сборке.
