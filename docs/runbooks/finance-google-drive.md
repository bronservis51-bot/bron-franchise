# Отчёт о доходах и расходах в Google Drive

В «Финансах» выберите месяц и точку или «Все точки». «Excel» скачивает книгу с отчётом и листом «Выручка по дням». «Google Drive» сохраняет лист «Доходы и расходы» по выбранному месяцу и точке. При сохранении владелец выбирает свой аккаунт Google. Файл появляется в «Мой диск», ссылка на него открывается из диалога.

## Подключение

1. В проекте Google Cloud включите Google Drive API и настройте экран согласия. Укажите `https://www.googleapis.com/auth/drive.file`. Для тестового режима добавьте владельцев тестовых аккаунтов в список пользователей.
2. Создайте OAuth Client ID типа **Web application**. Добавьте используемые адреса приложения в **Authorized JavaScript origins** в формате `https://домен`, без пути. Для локальной проверки добавьте `http://localhost` и `http://localhost:5173` либо фактический порт Vite.
3. Передайте публичный ID как `VITE_GOOGLE_DRIVE_CLIENT_ID` при сборке. Сборка добавит в CSP адреса Google Identity и загрузки файла. Если площадка устанавливает заголовок `Cross-Origin-Opener-Policy`, для диалога Google укажите `same-origin-allow-popups`.
4. Проверьте на тестовом аккаунте выбор Google-аккаунта, закрытие диалога без сохранения и открытие ссылки на сохранённый XLSX. Сверьте месяц, точку и числа с экраном «Финансы».

Кабинет запрашивает короткоживущий токен в момент сохранения. Отчёт загружается напрямую из браузера, токен хранится в пределах операции. Если ID не задан или прямое сохранение недоступно, скачайте XLSX из диалога и загрузите файл в свой Google Drive.

[Настройка Google Identity](https://developers.google.com/identity/oauth2/web/guides/get-google-api-clientid) · [Права Drive API](https://developers.google.com/workspace/drive/api/guides/api-specific-auth)

## Серверная выгрузка в книги организации

Служба `bron-google-finance` читает отчётный снимок из рабочей базы и обновляет
в каждой книге два листа «Кабинет — сводка» и «Кабинет — операции». В сводке
календарные месяцы, а в операциях даты фактических оплат роялти. Первоначальные
листы из Google и данные других систем ведутся в своих диапазонах. В отчёте
видны валюта, ключи строк и время удачной выгрузки. Суммы разных валют отдельно.

Перед выпуском учёта возвратов обновите `/opt/bron/google-finance` до версии, которая поддерживает возвраты и прошлый долг, и проверьте снимок через `--check`. Эта версия читает и предыдущий формат. После применения миграций и публикации приложения сверьте новые столбцы сводки и типы «Возврат покупателю» и «Прошлый долг по роялти» в операциях. Остаток учитывает возвраты, начисленные зарплата и роялти сохраняют прежнюю базу.

1. Сверьте личные права в каждой книге. Укажите книгу сети без `partnerId`, а
   каждую книгу партнёра со своим UUID из кабинета. Сопоставьте книгу и UUID с
   учётной записью партнёра. Для запуска достаточно одной внутренней книги.
   Для книг нужен доступ по конкретным аккаунтам. Служба проверяет доступ перед
   записью и привязывает свои листы к назначенной книге и партнёру.
2. Включите Google Sheets API и Google Drive API для отдельного сервисного
   аккаунта. После разрешения владельца дайте аккаунту доступ редактора к этим
   книгам. JSON-ключ храните в защищённом файле на сервере.
3. Используйте отдельный логин PostgreSQL. Выдайте только `USAGE` на
   `app_private` и `EXECUTE` на `app_private.google_finance_rows(date,date)`.
   TLS настраивается через `BRON_DB_CA_FILE` по правилам приложения.
4. Сохраните конфигурацию в защищённом JSON-файле со свойствами `fromMonth`
   (первое число начала истории в формате `YYYY-MM-01`) и `books` (массив
   записей `spreadsheetId`, необязательного `partnerId` и `permissions`). В
   `permissions` зафиксируйте подтверждённый список Drive `permission.id` и
   `role` для каждого получателя, включая владельца и сервисный аккаунт. При
   изменении получателей сверяйте и обновляйте этот список. В закрытом файле
   `/etc/bron-franchise/google-finance.env` задайте `GOOGLE_REPORT_CONFIG_PATH`,
   `GOOGLE_REPORT_DATABASE_URL` и `GOOGLE_REPORT_KEY_PATH`.
5. Разместите проверенную версию с npm-зависимостями в `/opt/bron/google-finance`
   и запустите `node scripts/sync-google-finance.mjs --check` от пользователя
   `bron-report`. Проверка читает снимок и выводит количество строк и книг.
   После одобрения выполните первый запуск службы. Сверьте в Google суммы,
   периоды, получателей и время выгрузки. Затем включите
   `bron-google-finance.timer` для почасового обновления.

Оба листа книги обновляются одним запросом. При отказе Google книга сохраняет
предыдущий снимок. Время обновления видно в сводке. Параллельный запуск
предотвращает блокировка в PostgreSQL. Если один файл перестал обновляться,
проверьте его права, доступность API и итог службы в журнале systemd.
