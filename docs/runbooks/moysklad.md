# Поставки из МойСклад

Кабинет читает защищённые месячные снимки. Себестоимость доступна только менеджеру; публичных таблиц с ней нет. Выручка розничных точек и ввод смен работают независимо от МойСклад.

## Загрузка

На доверенном сервере задайте `MOYSKLAD_READ_TOKEN` отдельного пользователя МойСклад с правами только чтения и `DATABASE_URL` через защищённое окружение. Они не должны иметь префикс `VITE_`, попадать в git или браузер. Подключение МойСклад в ChatGPT не передаёт приложению его секрет.

Запуск: `node scripts/sync-moysklad.mjs --month=2026-10`. Без аргумента загружается текущий месяц по московскому времени. Команда обходит все страницы `profit/bycounterparty`, учитывает возвраты и атомарно заменяет снимок. Ошибка API сохраняет последнюю успешную версию. Заказы и оплаты не прибавляются к отгрузкам. Деньги отчёта — учётные рубли, независимо от валюты розницы партнёра.

После размещения в России эту команду можно запускать расписанием сервера. Текущее и предыдущее месяцы нужно обновлять отдельно: задним числом могут появляться возвраты и исправления. Наличие файла скрипта само по себе не означает, что фоновое обновление уже включено.

## Привязки

UUID контрагента закрепляется за партнёром. В разделе «Экономика» менеджер видит непривязанные суммы и может проверить исходную карточку, затем привязать её. Совпадение одного имени не доказывает личность. Несколько подтверждённых карточек одного партнёра учитываются вместе; сами карточки МойСклад не меняются.

Кнопка «Обновить сводку» перечитывает последний снимок, а не вызывает МойСклад из браузера. Дата загрузки показана явно. Пустой период и отсутствие привязки отображаются как неизвестные данные, а не как нулевые продажи.
