# Личная проверка доступа и ключа без Mac — T30

Это две проверки: вы можете войти к серверу с другого устройства, и ваша
независимая копия ключа действительно расшифровывает резервную копию. Они нужны,
чтобы потеря Mac не лишила нас сервера и восстановления. Это не проверка сайта
на телефоне: приёмка сайта будет позже. Live-сверка T37 может идти параллельно.

1. На **телефоне** откройте официальный кабинет
   [my.adminvps.ru](https://my.adminvps.ru/). Войдите своим обычным способом;
   код MFA вводите только на сайте. Не присылайте пароль или код в чат.
2. Откройте список ваших услуг и выберите существующий VPS с адресом
   **152.228.115.115**, услуга **386078**. Ничего не покупайте и не переустанавливайте.
3. В карточке услуги откройте управление сервером и **веб-консоль / VNC**.
   Точное расположение кнопки в вашем кабинете ещё не подтверждено. Если её
   не видно, достаточно сообщить названия доступных кнопок, без скриншота секретов.
4. Нужен терминал сервера с приглашением пользователя `root`. Если вместо него
   экран входа `login:` или запрошен неизвестный пароль Linux — **остановитесь**
   и сообщите только «консоль требует вход Linux». Пароль кабинета AdminVPS
   не обязательно является паролем Linux. Не сбрасывайте пароль и не перезагружайте VPS.
5. Если у вас уже есть **независимая сохранённая копия ключа резервирования**
   (например, в вашем менеджере паролей на телефоне), найдите запись со строкой,
   начинающейся с `AGE-SECRET-KEY-`. Это отдельный ключ, не пароль сайта, SSH или AdminVPS.
   Если такой копии нет или вы не знаете, где она, сообщите «независимый ключ не найден».
   Не ищите ключ в файлах самого VPS и не передавайте его через Mac. Тогда мы
   отдельно подготовим безопасную передачу ключа в ваше независимое хранилище.
6. Только при открытом root-терминале и наличии этой копии выполните:

   ```sh
   bash /root/bron-secrets/t30-owner-verify.sh
   ```

7. После строки «Введите только строку AGE-SECRET-KEY…» введите/вставьте **только
   эту строку** непосредственно в консоль телефона и нажмите Enter. Символы
   намеренно не отображаются. Проверка читает копию на VPS; ключ и расшифрованное
   содержимое не сохраняются helper-ом, backup не скачивается на телефон или Mac.
8. Дождитесь результата. Исполнитель прочитает сохранённый технический JSON без
   ключа. В чат достаточно написать: «вошёл с телефона; ключ взят из [название
   хранилища]; проверка завершилась» либо безопасное сообщение об ошибке.
   Ни ключ, ни скриншот с ключом не нужны. Отдельно подтвердите, что копия ключа
   останется доступной, даже если Mac недоступен. Это подтверждение не заменяет
   криптографический PASS, а PASS не доказывает независимое хранение сам по себе.

Проверка T30 уже разрешена. Исполнитель не вводит ключ за владельца и не читает
серверный identity. Если helper выдаёт `T30_OWNER_PREFLIGHT_BLOCKED`, не повторяйте
ввод: сообщите этот код, чтобы сначала проверить причину.
