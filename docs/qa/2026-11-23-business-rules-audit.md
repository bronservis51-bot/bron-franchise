# Аудит реестра бизнес-правил

23 ноября 2026, МСК. Пройдены сценарии для всех 32 правил реестра из коммита `5ddc7cc`. База для сравнения — рабочая версия кабинета `1a94038`. Для операций записи использовалась изолированная база, для интерфейса — локальный Chromium. Анкета лендинга проверена на версии из реестра с перехватом запросов. Доступ к опубликованному лендингу из среды проверки и подтверждение реальных предзаказов у поставщика остались открыты. [Реестр бизнес-правил](../business-rules.md)

## Приоритеты доработок

1. **Условия оплаты и сдача смены.** Показывать франчайзи действующий способ оплаты до редактирования, выводить только его поля и пример начисления. Сотруднику достаточно одной формы с точкой, датой, суммами и статусом отправки. Это два изменения следующего выпуска.
2. **Выручка и начисления.** Показывать на «Всех точках» дни, где поздняя смена изменила прежний итог. Менеджеру сети дать переход из счётчика в точку и дату. Сравнить данные в кабинете, отчёте и выгрузке.
3. **Сверка роялти.** Сейчас оплата текущего месяца уменьшает общий долг в сетевой сводке, но не в карточке партнёра и отчёте франчайзи. Согласовать смысл оплаты и корректировки открытого месяца, затем использовать один расчёт и явно показать начисление месяца отдельно. Причину корректировки следует либо показывать франчайзи, либо снять обещание об этом в форме.
4. **Входящие заявки и закупки.** Проверять содержимое успешного ответа анкеты. Явно показывать предпочитаемый способ связи. При замене личной ссылки на магазин заново подтверждать доступ даже при возврате к прежнему адресу. Ошибка снимка поставок не должна скрывать доступную розницу и роялти.
5. **История ознакомления.** Дать из текущей редакции открыть историю прежних подтверждений. Для ручной публикации инструкций показать автору способ указать область действия и источник.
