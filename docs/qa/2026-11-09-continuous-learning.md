# Проверка непрерывного обучения

Критерии: два урока в один день, немедленный повтор после незачёта, более десяти
вопросов в банке, персональная зелёная точка, отсутствие ключей до ответа, изоляция
локальных вопросов, версия изменений, неизменность результата при повторе,
разные аудитории и стажировка с сохранением условий открытой смены.

Проверены БД/PGlite, TypeScript и сборка; существующие финансовые/доступные проверки
сохранены. Рабочая копия успешно восстановлена отдельно, исходные бизнес-записи
сверены. Включение реальных материалов не создаёт фиктивных попыток сотрудников.

Браузерная матрица: 72/72 сочетаний четырёх экранов с девятью ширинами от 320 до
1920 px, текст 100% и 200%. Проверены загруженные компоненты, переполнение страницы
и размеры полей. Вручную проверены предупреждение о выходе, изучение → тест →
результат → следующий урок. Проверка Chrome/iframe не заменяет Safari и клавиатуру
физического iPhone. Реальные видео без проверенного содержания остаются вне тестов.

Публикация и рабочий вход подтверждаются отдельно по целевой сборке; этот документ
не объявляет приложение опубликованным до завершения Pages.
