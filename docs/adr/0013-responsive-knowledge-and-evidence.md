# ADR-0013 Мобильная вёрстка и проверяемая база знаний

Статус: принято, 2026-11-04.

У вложенной мобильной сетки сохранялась автоматическая минимальная ширина, а
длинные документы растягивали flex-строки. В заголовке раздела знаний кнопки
сжимали текст. Сетка ограничивается доступной шириной, текст переносится,
на узком экране действия раздела занимают отдельную строку. Общие компоненты
проверяются с длинными данными и увеличенным текстом; скрытие переполнения всей
страницы не считается исправлением.

В опубликованных материалах смешивались корпоративные документы, старые шаблоны,
сторонние видео и сгенерированные советы. После сверки сохраняются только
подтверждённые положения с источником и датой. Неизвестные условия остаются
незаполненными, дубликаты архивируются, история сохраняется. Недостающие темы
представлены разделами и пустыми редакторскими черновиками.

Учебный сайт интегрируется через проверенные ссылки на отдельные уроки и
оглавление, без копирования Google Sites в iframe и без выдуманной расшифровки.
Видеоплееры создаются по действию пользователя, внешняя ссылка остаётся доступной.
Просмотр страницы не считается подтверждённым прохождением курса.

Схема ролей, RLS и контракты лендинга не меняются. Массовое редактирование контента
проводится по закрытому плану с контролем исходных версий, пробным восстановлением
и проверкой повторного применения. Внутренние источники не публикуются в коде.
