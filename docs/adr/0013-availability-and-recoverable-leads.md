# ADR-0013 Контролируемые сбои и восстановимое удаление заявок

Статус: принято 09.11.2026. Российский шлюз подготовлен, размещение требует
отдельного подтверждённого сервера. Это не завершённый перенос базы в РФ.

Несколько устройств получают таймаут предварительной проверки Auth, тогда как
проект ACTIVE_HEALTHY и другие клиенты успешно читают заявки. Исторический текст
«запрос не доходит» выдавал предположение за диагноз. Внешняя проверка не
подтверждает доступность с конкретной российской сети.

- Отдельные ограниченные по времени read-only проверки Auth и PostgreSQL не
  блокируют вход. Отмена старой проверки не меняет новую после размонтирования.
- Самостоятельная help.html доступна без Auth и основной React-оболочки. Копия
  диагностики содержит только время, сборку, online и результаты двух проверок.
  Пароль, URL query, токены, клиентские данные и storage не читаются.
- GitHub Actions проверяет примерно раз в пять минут опубликованную версию,
  Auth, ping и контракт лендинга через honeypot без вставки заявки. Public
  ops-status содержит время и результаты. Проверка старше 30 минут не зелёная.
  Это внешний контроль, а не проверка входа директора; запуск может задерживаться.
- Отдельная рассылка не настроена: канал и технический дежурный не назначены.
  История ошибок доступна в Actions. Разовая копия не равна регулярному backup.
- Прежние JWT, require_user/session_id/RLS сохраняются. Нельзя восстанавливать
  доступ отключением авторизации, общим паролем или публичной выгрузкой заявок.
- gateway/ подготовлен для российского размещения: фиксированный upstream,
  allowlist путей/заголовков/источников, исходный JWT, no-store, предел тела/времени,
  без cookie и логирования содержимого. Это промежуточный маршрут, а не перенос БД.
  Повтора записи по второму адресу после неизвестного результата нет.
- Удаление CRM переводит строку в корзину. Подтверждение, org.manage, версия и
  аудит; восстановление сохраняет UUID, стадию, анкету. Старые клиенты не могут
  редактировать удалённую строку. «Отказ» не означает удаление.

Инцидент закрывается после обычного входа и чтения заявок на пострадавшей сети.
Корзина и инструкции не заменяют копии, дежурство и мониторинг из РФ.
