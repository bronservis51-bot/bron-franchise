# ADR-0020 — установка PWA до входа

Статус: принято. Дополняет ADR-0008, не меняет авторизацию и обновление приложения.

## Решение

- На экране входа и в профиле есть одна инструкция установки с выбором устройства.
  Подсказка после входа открывает тот же компонент. Инструкцию можно закрыть,
  установка не обязательна и не очищает форму входа.
- `beforeinstallprompt` перехватывается при старте приложения, до монтирования
  React. Системный запрос вызывается только по нажатию пользователя и один раз на
  полученное событие. При отсутствии события, отказе и ошибке остаётся инструкция.
- iOS получает ручные шаги, включая iPad с настольным user agent. Принятый запрос
  не означает завершённую установку: подтверждение — `appinstalled` или standalone.
  Не записываем постоянный признак «установлено» в localStorage.
- Копируется только origin + базовый путь, без маршрута и параметров сессии.
  Никаких новых разрешений камеры, уведомлений и фоновой синхронизации нет.
- На временном GitHub-адресе предупреждаем о повторной установке после переезда.
  Массовую установку проводим после перехода на постоянный HTTPS-домен.

## Ограничения

Браузер определяет доступность системной установки; скрипт не может нажать за
пользователя «Добавить» на iPhone. Переход на другой origin не переносит PWA,
сессию и IndexedDB. До перехода отправляем очередь, затем пользователи входят и
устанавливают приложение заново. Изменение здесь не переносит базу данных в РФ.
