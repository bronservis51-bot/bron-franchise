# ADR-0016. Простые закупки, итог выручки дня и управляющий

Дата: 2026-11-09. Статус: принято по запросу владельца.

## Решение

Основной `/order` снова содержит «Заказ» (существующий персональный магазин МойСклад)
и «Предзаказ» (Tilda с обязательным согласованием возможности, срока и цены).
ADR-0015 приостановлен в части интерфейса и планового обработчика. Его данные и
код сохраняются; персональные магазины, их цены, контрагенты и заявки не меняются.
Запуск единого магазина потребует отдельного решения и сквозной проверки.

Владелец вводит всю выручку точки за день. `reported_total_minor` — заявленный итог,
`unallocated_minor` — часть этого итога, ещё не покрытая закрытыми сменами.
Общая выручка = сумма смен + max(заявленный итог − сумма смен, 0).
Наличные/карта фиксируются сотрудником при закрытии смены; неизвестный способ
оплаты не подменяется наличными. Старые импортированные записи остаются как были.
Если смены превысили заявленный итог, фактом становится сумма смен, а владелец
видит расхождение. Ввод суммы ниже уже закрытых смен отклоняется. Зарплата
считается по смене и её сохранённым условиям; декларация владельца её не меняет.

Все пути записи выручки сериализуются по точке/дню. Новая команда проверяет
версию всего дня и сохраняет квитанцию операции. Повтор не создаёт новую запись;
конфликт, в том числе из офлайн-очереди, требует сверки. Старый клиент не может
перезаписать декларацию через поля наличных/карты.

`franchisee_manager` — управляющий одного франчайзи: закупки, управление его
продавцами и база знаний. Нет финансов владельца, рейтинга сети, создания
владельцев/других управляющих. Владельцы и менеджер сети создают управляющих.
Удаление — отзыв доступа, не удаление истории. Закрываются серверные сессии;
восстановление требует нового входа. Компания/владелец не становятся управляемыми
через случайную дополнительную запись сотрудника.

Рейтинг для франчайзи исключает заполняемость и её значки на сервере. Порядок
теперь по фактическому проценту плана, затем выручке; прогноз не выдаётся за факт.
Сводный план не показывается полным, если план есть не у всех входящих точек.

Два аккаунта могут работать в отдельных вкладках с `?profile=manager` и без
параметра: отдельные ключи Auth, cache и BroadcastChannel. Параметр не даёт прав
и не выполняет вход. Каждый аккаунт проходит обычную авторизацию.

На телефоне прокручивается содержимое, нижнее меню — часть ограниченного по
высоте контейнера. Высота учитывает visualViewport; при клавиатуре меню скрыто.
По явному запросу владельца жест изменения масштаба отключён на мобильной ширине.
Увеличение текста остаётся доступно. Эмуляция не подтверждает поведение физического
Safari/PWA с клавиатурой: требуется проверка на iPhone.
